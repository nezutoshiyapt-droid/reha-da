# 🍣 リハ打（REHA-DA）

医療・リハビリテーションの専門用語と臨床会話で遊べる、寿司打スタイルの日本語タイピングゲームです。

**▶ 遊ぶ：** https://nezutoshiyapt-droid.github.io/reha-da/

> ⚠️ 物理キーボードが必要です。PC（Windows / Mac）のブラウザで開いてください。
> 日本語入力（IME）はオフの状態でプレイします。

## あそびかた

- 右から流れてくるお皿の言葉を、**ローマ字で**打ち切ります
- お皿が左端に着く＝時間切れ。次のお皿に進みます
- お皿の流れる速さは **どのコースでも、どんな長さの言葉でも一定**（1皿あたり7秒・148.6 px/秒）
- 制限時間内に **コース料金より多く食べれば「元が取れた」**

### コース

| コース | 料金 | 制限時間 | お題の長さ | 間に合う打鍵速度 |
|---|---|---|---|---|
| お手軽 | 2,500円 | 60秒 | 6〜13文字 | 約1.5キー/秒 |
| お勧め | 4,000円 | 90秒 | 14〜20文字 | 約2.4キー/秒 |
| 高級 | 6,000円 | 120秒 | 21〜29文字 | 約3.6キー/秒 |
| 特上 | 7,000円 | 120秒 | 28文字以上（臨床会話文） | 約4.8キー/秒 |

回転スピードは**4コースとも完全に同じ**（1皿7秒 / 148.6 px/秒）。
難易度の差は **お題の文字数・制限時間・料金** だけでついています。
各コース内は文字数をそろえてあるので、**どの皿も同じ手応え**になります。

### ルール

- **連続正答ボーナス** — 3皿連続で+0.3秒、6皿で+0.5秒、10皿で+0.8秒、15皿で+1.0秒（加算上限は制限時間の30%）
- ミスタイプ・取りこぼしで連続はリセット
- **✨金皿**（出現率12%）は値段2倍
- 連続正答が10皿を超えるとBGMが少し速くなります（皿の速さは変わりません）

### キー操作

| キー | 動作 |
|---|---|
| `Enter` | スタート / リトライ |
| `Esc` | 中断してリザルトへ |
| `F2` | BGM・効果音のオン/オフ |

## ローマ字入力について

複数の打ち方に対応しています。

- `shi` / `si`、`tsu` / `tu`、`ja` / `jya` / `zya`、`fu` / `hu` など
- 「ん」は `nn` / `n`（母音・な行・や行の前と語末は `nn`）
- 促音「っ」は子音重ね（`kk`, `ss` …）または `xtu` / `ltu`
- 伸ばし棒「ー」は `-` キー

## 技術メモ

- **依存関係なし・外部通信なし**の HTML 1ファイル（約52KB）
- BGM・効果音はすべて Web Audio API による合成音（音源ファイル不要）
- ローマ字判定は、かな1文字ずつを非決定性オートマトンで照合する方式
