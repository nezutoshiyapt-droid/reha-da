# 🍣 リハ打（REHA-DA）

医療・リハビリテーションの専門用語と臨床会話で遊べる、寿司打スタイルの日本語タイピングゲームです。

**▶ 遊ぶ：** https://USERNAME.github.io/REPO/

> ⚠️ 物理キーボードが必要です。PC（Windows / Mac）のブラウザで開いてください。
> 日本語入力（IME）はオフの状態でプレイします。

## あそびかた

- 右から流れてくるお皿の言葉を、**ローマ字で**打ち切ります
- お皿が左端に着く＝時間切れ。次のお皿に進みます
- 制限時間内に **コース料金より多く食べれば「元が取れた」**

### コース

| コース | 料金 | 制限時間 | 内容 |
|---|---|---|---|
| お手軽 | 3,000円 | 60秒 | 短めの単語中心 |
| お勧め | 4,500円 | 90秒 | 専門用語をバランスよく |
| 高級 | 6,000円 | 120秒 | 長い用語＆臨床会話文 |

### ルール

- **連続正答ボーナス** — 3皿連続で+0.3秒、6皿で+0.5秒、10皿で+0.8秒、15皿で+1.0秒（加算上限は制限時間の30%）
- ミスタイプ・取りこぼしで連続はリセット
- **✨金皿**（出現率12%）は値段2倍
- 時間経過とともに1皿あたりの持ち時間が短くなります

### キー操作

| キー | 動作 |
|---|---|
| `Enter` | スタート / リトライ |
| `Esc` | 中断してリザルトへ |
| `F2` | BGM・効果音のオン/オフ |

## 出題カテゴリ（全181問）

- **解剖・運動器** — 大腿骨、回旋筋腱板、腕神経叢 など
- **評価・検査** — 徒手筋力検査、6分間歩行試験、機能的自立度評価 など
- **疾患・病態** — 腰部脊柱管狭窄症、筋萎縮性側索硬化症、廃用症候群 など
- **治療・介入** — 関節可動域訓練、呼吸理学療法、装具療法 など
- **臨床の会話文** — 「痛みがあれば遠慮なく教えてください」など

スタート画面でカテゴリを選べます。

## ローマ字入力について

複数の打ち方に対応しています。

- `shi` / `si`、`tsu` / `tu`、`ja` / `jya` / `zya`、`fu` / `hu` など
- 「ん」は `nn` / `n`（母音・な行・や行の前と語末は `nn`）
- 促音「っ」は子音重ね（`kk`, `ss` …）または `xtu` / `ltu`
- 伸ばし棒「ー」は `-` キー

## 技術メモ

- **依存関係なし・外部通信なし**の HTML 1ファイル（約52KB）
- BGM・効果音はすべて Web Audio API による合成音（音源ファイル不要）
- ローマ字判定は、かな1文字ずつを非決定性オートマトンで照合する方式
